Скриншоты, фото и макеты для [`../VISUALS.md`](../VISUALS.md).

Имя файла привязано к ID визуала: `v-05-1-<slug>.png` — по имени видно, к какой схеме
относится файл, и осиротевшие изображения находятся глазами.

Крупные исходники (Figma, PSD, .sketch) в репозиторий не кладутся — вместо них ссылка
в `VISUALS.md` плюс экспортированный скриншот здесь.
