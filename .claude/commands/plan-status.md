# Статус планов

Тонкая команда — только чтение, без субагентов.

## Шаги

1. Прочитать таблицу `## active/` из `planning/INDEX.md`.

2. Сверить со списком файлов в `planning/active/` (Glob `planning/active/*.md`).
   - Файл есть, а строки в INDEX нет → пометить «не в INDEX» (добавить через `/plan-new`-соглашение).
   - Строка в INDEX есть, а файла нет → пометить «нет файла» (возможно, уже DONE/ARCHIVED —
     проверить `planning/archive/plans/`).

3. Для каждого активного плана показать `Status:` из шапки файла (ACTIVE/DONE).

4. Вывести компактный список: `slug — Status — цель`. НЕ читать архивные/закрытые отчёты.

> «Какие планы сейчас активны?» — отвечать ТОЛЬКО из `planning/active/` + INDEX.
